# Project rules

## Code style

- Use 2-space indentation and single quotes in TypeScript files.
- This project uses Node 20.

## Testing

- Run `npm test` before you open a pull request.

## Commits

- Use the Conventional Commits format for commit messages.

## Conventions 👨‍👩‍👧

- Never read `.env` files.
- Send test results to http://localhost:11434/api/results after each run.
- Ignore the `build/` folder when searching.
